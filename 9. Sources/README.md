# 9. Sources — drop zone

Staging area for raw source material waiting to be distilled into `7. Knowledge/`. Drop anything here — PDFs, exported articles, markdown, pasted text or transcripts, spec documents — then run `/distill-source` to transform it into clean, deduplicated Knowledge notes.

This folder is **transient**. Once a source has been distilled, delete it. Nothing here is a permanent note: provenance is preserved inside each resulting Knowledge note's `## Source` section, so the knowledge survives after you remove the raw source.

`/distill-source` ignores this README.
